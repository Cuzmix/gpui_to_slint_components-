# Porting gaps

Every place where the Slint port cannot reproduce the GPUI original exactly. Numbers are stable: a gap that closes is removed and its number is not reused (G4, platform detection, closed once Slint's `Platform.os` was used; G15, presses inside a TooltipTrigger, which tests showed already hide the tip). Each row: the GPUI behavior, the Slint limitation, the workaround, and the difference that remains on screen.

| # | Component | GPUI behavior | Slint limitation | Workaround | Remaining visible difference |
|---|---|---|---|---|---|
| G1 | Theme | Changing mode, high contrast, color-blind charts or a custom palette cross-fades every color over 280 ms (ease-in-out-cubic), driven by the app. | A `global` cannot hold `animate`, `states` or a `Timer`. | `ThemeFader` component placed once per window runs the 8 ms frame timer and writes `Theme.fade`; `Theme.colors` blends `fade-from` → `fade-to`. | None when a `ThemeFader` is in the window. Without one, changes apply at once. Removing the fader mid-fade leaves the blend where it stopped. |
| G2 | Theme | Colors blend in 32-bit float sRGB. | Slint colors are 8 bits per channel; Slint's own `mix` is SASS-style and differs when alphas differ. | `Palettes.mix` reimplements GPUI's straight per-channel lerp. | Up to 1/255 per channel from 8-bit rounding. |
| G3 | Elevation (Tooltip, later menus, dialogs) | Two `BoxShadow` layers per level. | One drop shadow per element. | `Elevated` stacks a same-size child carrying the second layer. | Layers match; gpui's blur kernel and Slint's `drop-shadow-blur` may not fall off identically, so the shadow edge can look slightly softer or harder. Not measured against a GPUI capture yet. |
| G5 | Spinner | Arcs are polylines of 32 segments per full turn. | None; Slint draws true arcs. | `Path` with `ArcTo`. | The ring is slightly smoother than GPUI's 32-segment polygon. |
| G6 | Tooltip | gpui shows tooltips from its own hover tracking on any element, including on touch long press. | Slint has no tooltip hook; a nested TouchArea would steal the host's clicks. | `TooltipController` is fed the host TouchArea's pointer events (`pointer-event`, `dismiss`). | Touch long-press tooltips are not implemented. |
| G7 | Tooltip | Flips left or up when it would leave the window (`prepaint_tooltip`). | A `PopupWindow` cannot read its absolute position or the window size from inside, before it is shown. | None yet; Slint keeps popups inside the window on its own. | Near the right or bottom edge the tip is pushed inside instead of flipping to the other side of the pointer. Not yet verified on every backend. |
| G8 | Button | `shortcut("secondary-s")` parses gpui key syntax and spells it per platform. | `.slint` has no string splitting. | `Button.shortcut` takes the spelled text; `ely_slint::shortcut_text` ports gpui's parser and Ely's key caps exactly. | None when the host uses the Rust helper. Pure-Slint users type the caps themselves. |
| G9 | Button (link) | Hover underlines the label with gpui's text underline. | Slint 1.18 `Text` has no underline. | A 1 px rectangle in the label color under the text. | The underline's distance from the baseline is estimated from the font size, so it can sit a pixel or two off. |
| G10 | IconButton | Without a tooltip, the accessible name is the icon's Lucide name. | A Slint `image` does not carry its file name. | `icon-name` property; `CloseButton`, `BackButton`, `MoreButton` set it. | None if the owner sets `icon-name` or `tooltip`; otherwise the button has no accessible name. |
| G11 | Button, IconButton | `disabled(bool)`. | None; naming only. | Slint's idiomatic `enabled` (inverse). | None. |
| G12 | Backdrop | Raised over the whole window from anywhere in the tree (`anchored` + `raise`), sized to the viewport. | Slint has no portal: an element draws inside its parent. A PopupWindow would cover the window but steals all input and closes on outside clicks. | `Backdrop` fills its parent; the owner puts it last in the window (or in the box it should cover). | None when placed at the window root. Placed deeper, it covers only its parent. |
| G13 | Picture | `img()` loads files and URLs on gpui's executor and shows the loading pane until the bytes decode; a decode error shows `image-off`. | Slint decodes local `@image-url` and `Image::load_from_path` synchronously and has no network loader in `.slint`. | `loading` is an input the host sets while it fetches; `failed` is a source that decoded to nothing (`source.width == 0`). | None when the host drives `loading`. Without it, a slow network picture shows the placeholder instead of the pulse. |
| G14 | Disclosure | Each change restarts the turn from the other end: toggled mid-turn, the chevron jumps to the far angle and turns again. | Slint's `animate` always continues from the current value. | None. | Toggled during the 120 ms turn, the chevron reverses smoothly from where it is instead of jumping first. |
| G16 | Measure | Reports after paint, then requests one more frame so what the report changed shows. | Slint has no after-paint hook. | Reports from `init` and from `changed` handlers on `absolute-position`, width and height. | Reports come in the same frame instead of after it; values match. |
| G17 | IntersectionObserver | Compares its bounds with the clip it paints under (`content_mask`), so any scroll container or the window edge counts. | Slint does not expose an element's clip or visible region. | The owner passes the visible area (`visible-x`/`-y`/`-width`/`-height`, window coordinates), for example a Flickable's viewport. | None when the owner passes the right area; otherwise it reports against whatever area it is given. |
| G18 | FocusTrap | Tab and Shift-Tab wrap inside the trap with gpui's `focus_next`/`focus_prev`. | `.slint` cannot move focus by one Tab stop; only Slint's own Tab handling does. | Sentinel stops at both ends catch focus as it leaves and call `FocusSteps.step`; the host wires that to `ely_slint::focus::step` (it sends the window a Tab or Backtab). | None when wired. Unwired, a wrap stops once on an invisible sentinel and the next Tab moves on. |
| G19 | FocusScope `.root()` | The root scope takes focus when the focused element leaves the tree, so window key bindings keep working; it hands focus back past overlays that left unclosed. | Slint clears focus when the focused element is removed and raises no event for it; with nothing focused, no FocusScope receives keys. | None generic. Each overlay in this port hands focus back itself when it closes; an owner that removes focused content calls `focus()` on its own scope. | After the focused element disappears without its owner refocusing, keys go nowhere until the user clicks or presses Tab. |
| G20 | Typography (`tabular`, `literal`; Code, Kbd, value texts) | Turns on OpenType features: tabular figures (`tnum`) so digits line up, and no ligatures (`calt`, `liga` off) so `==` stays two signs. | Slint 1.18 `Text` has no font-feature setting. | None; Inter's default figures are proportional, JetBrains Mono's are already fixed width. | Proportional digits in Inter number columns can shift by a fraction of a pixel per digit. JetBrains Mono draws its coding ligatures (`==`, `->`) as joined signs. |
| G21 | Blockquote | Children inherit the quote's muted ink and medium size through gpui's text style cascade. | Slint has no style inheritance: each text sets its own. | `text` draws a passage in the quote's style; `ink` and `text-size` are outputs children can bind to. | None for `text` or children that bind `ink`/`text-size`; other children keep their own style. |
| G22 | Highlight | One `StyledText` with background highlights, so marked text wraps and kerns as one line. | Slint's `StyledText` has no background color, and runs in separate Texts cannot wrap together. | Each run is its own Text in a row; marked runs sit on a `warning-subtle` rectangle. | The text does not wrap. Each run's width rounds up to a whole pixel, so text after a mark can sit up to 1 px further right per run, and kerning across a run edge is lost. |
| G23 | Ellipsis, MiddleEllipsis, EllipsisTooltip | Compares a cut's shaped width with the box in fractional pixels. | Slint reports a Text's preferred width rounded up to a whole pixel. | None needed for most text. | When a cut would fit with less than a pixel to spare, the line can keep one character fewer than gpui, or show its tooltip one pixel earlier. |
| G24 | Link, ExternalLink | The element's role is `Link`, so assistive technology announces a link. | Slint 1.18's `AccessibleRole` has no link. | Role `button`, label the text, default action runs it. | Screen readers announce a button instead of a link. |
| G25 | Value texts (NumberText, CurrencyText, PercentText, FileSizeText, DurationText, PluralText, RelativeTime, DateTimeText) | Takes `f64` values, `u64` counts, bytes and seconds, and 64-bit timestamps. | Slint's `float` is 32-bit and `int` is `i32`. | Floats keep about seven significant digits; counts and seconds stop at 2,147,483,647; moments are `i32` Unix seconds. FileSizeText takes a float, which is exact to 16 MB and within 0.00001 % above. | Amounts past seven significant digits (above 99,999.99 with cents) can round in the last cent. Moments after January 2038 cannot be given. Durations past 68 years and counts past 2.1 billion cannot be given. |
| G26 | RelativeTime (and every `@tr` string) | Ships seven locales (en, de, fr, ja, he, zh-CN, …) selected at run time. | Slint translations are gettext catalogs bundled at build time or loaded by the host. | Strings are marked with `@tr` with plural forms; catalogs come with the i18n chapter. | Until then every string reads in English. |
| G27 | SelectableText | gpui's own selection: press, shift-press and drag only; not a Tab stop; keys other than copy and select-all pass on to parents. | Slint's selectable text is a read-only TextInput, which selects a word on double press and a line on triple press, takes Tab focus, and handles moving keys itself. | Moving keys are swallowed so the selection never moves by keyboard; the caret is hidden. | Double and triple press select a word or line. Tab stops on the text. Arrow, Home, End and Page keys pressed while it has focus do not reach parent handlers. |
| G28 | GradientText, ShimmerText | Colored runs in one gpui text, at the ambient line height (phi). | Slint's `StyledText` (the only per-run color element) has no line-height setting. | The text sits centered in a box one ambient line tall, so a single line matches. | Text that wraps to more lines keeps the face's own line spacing (about 1.21 × size instead of 1.62), so a wrapped gradient or shimmer is shorter than gpui's. |
| G29 | LineClamp, Blockquote, SelectableText, TintedText, GradientText, ShimmerText | A wrapping text sizes to its content wherever it sits, and `.line_clamp(n)` caps it at n lines. | Slint 1.18 loops when an element binds its height to a word-wrapped child's preferred height inside a FlexboxLayout, and ignores `max-height` on word-wrapped Text. | These components are layouts (or carry `preferred-height`/`max-height` on a frame), so the parent layout sizes them; LineClamp clips its text inside a frame that carries the clamp. | Placed in a layout, none. Placed with `x`/`y` in a plain element, they fill that element's height, as any Slint layout does. |
| G30 | Emoji (and emoji inside any text) | Draws the system color emoji font. | Slint's software renderer cannot draw bitmap color fonts such as Noto Color Emoji; it falls back to an outline face. | None; the FemtoVG and Skia renderers draw color emoji. | With the software renderer (and in the headless gallery captures), emoji show as small monochrome glyphs. |
| G31 | ScrollArea (and every Flickable-based scroll) | A wheel step moves the offset at once; a wheel event along an axis the box can scroll stops at the box, even at its end. | Slint's Flickable eases each mouse-wheel step over a short physics animation, and passes a wheel event on to the parent once the box is at its end and a short capture window has passed. | None. | Wheel steps glide for a few frames instead of jumping. Scrolling past the end of a nested area scrolls the page around it after a moment, where gpui keeps the wheel in the inner area. |
| G32 | Accordion | Holds any number of items and opens and shuts them itself. | A Slint component cannot give state to children the owner declares. | The accordion keeps the open set as bits of an `int` and offers `is-open(i)` and `toggle(i)`; each item binds to them by its index. | Items past the 31st cannot open. Each item names its own index. |
| G33 | Dock, PaneGroup | The owner hands a closure that draws a panel's or pane's body, and the component puts it in place. | A Slint component cannot take a component as a value, and `@children` has one slot. | The component draws the chrome and exposes each body's box (`body-x(side)`, `body-x(cell)`, ...); the owner draws its bodies there with a `for`, and wraps floating bodies in `DockFloat`. | None once the owner places the bodies; it is more code at the call site. |
| G34 | Dock zones | A 2 px dashed outline. | Slint has no dashed borders. | 4 px dashes with 2 px gaps along each edge, and solid quarter-round corners. | The dash rhythm differs from gpui's renderer, and the corners are solid. |
| G35 | PaneGroup | A left press anywhere in a pane, even on its body's own controls, focuses the pane (gpui mouse-down listeners run for every element under the pointer). | A Slint TouchArea takes the press; the one under it does not see it. | The pane's chrome focuses on presses that reach it; its header buttons focus the pane when clicked. | A body control that takes presses must call `PaneGroups.focus` itself, or pressing it leaves focus where it was. |
| G36 | Disclosure, Spinner (and any `transform-rotation`) | gpui rotates the chevron or ring as it animates. | Slint's software renderer draws elements unrotated; FemtoVG and Skia rotate them. | None; rotation is set as in the source. | With the software renderer (and in the headless gallery captures), chevrons don't turn and spinners don't spin. |
| G37 | TitleBar, WindowControls, WindowDragRegion, ResizeBorder, ZoomControl (every window act) | Components call gpui's `Window` directly: move, resize, minimize, zoom, close, and read whether the window is active, maximized, full screen or client-decorated. | `.slint` cannot reach its window. | The `WindowChrome` global carries the acts as callbacks and the state as properties; `wire_window!` answers them with winit (`drag_window`, `drag_resize_window`) and keeps the state current from winit's events. | Unwired, the acts do nothing and the state keeps its defaults (active, not maximized). A window winit does not back (the testing backend) logs moves and resizes and stays put. Tiling is all edges or none (maximized or full screen); winit does not report Wayland's per-edge tiling. |
| G38 | WindowDragRegion, WindowControls on Windows and macOS | Windows hit-tests the drag region and caption buttons natively (`WindowControlArea`), so Snap, the system menu and the snap layouts flyout work; a macOS double click follows the user's Dock setting (`titlebar_double_click`). | winit offers `drag_window` only, and no caption hit-testing or the macOS setting. | The region moves the window on the first move of a press; a double click zooms on every system. | On Windows, no snap layouts flyout over Maximize and no system menu on the bar; a double click zooms as Windows would. On macOS a double click zooms even when the user set it to minimize or do nothing. |
| G39 | TitleBar, ColumnShell (close routing) | While the bar is drawn with an `on_close` and no forced platform, the system's close runs that handler; once it is gone, closes go through. | Slint has no hook when a component goes away. | The bar sets `WindowChrome.close-routed` while it routes; the host then holds the close back and bumps `close-asked`, which the bar answers. | A routing bar removed from the tree leaves the flag set, so system closes stay held back: set `handles-close` false (or the platform) before removing it. |
| G40 | ZoomControl | Scales the window's rem size, so rem-sized parts grow and pixel sizes stay. | Slint has no rem scale over the theme's pixel tokens. | The host changes the window's scale factor, so the whole window, pixel sizes included, scales; the window keeps its size on screen. | Pixel-sized parts (hairlines, fixed widths) scale too. A system change of the display scale resets the zoom. |
| G41 | TitleBar | Separate slots for leading items and actions, each one block that takes presses; the title centers between equal halves. | A component has one `@children`. | The bar's children sit in one row 8 px apart; the title is the `TitleBarTitle` part among them, which centers in the bar given `bar: bar.frame`. | Presses in the 8 px gaps between items drag the window, where gpui's slot took them. Without the `bar` binding the title centers in its own room. |
| G42 | ColumnShell, ShellColumn | Each column carries its header items, title and body, and the shell lays them out with flexbox. | A component has one `@children`, and Slint's box layout does not shrink set widths by their bases as CSS flexbox does. | Rust lays the columns out as taffy would (`ely_slint::columns`); the shell draws ground, borders, handles and controls; the owner places `ShellColumnHeader` and `ShellColumnBody` with `column: shell.frames[ix]`. Widths sit apart from the constant `columns`, so a drag survives the owner's new width. | More code at the call site. A header's least width is its padding, controls and 32 px, not its fixed items, so a wide fixed item scrolls instead of holding the column wider. |
| G43 | ProgressBar, ProgressRing (and SplashScreen's progress) | Panics on a value or buffer outside 0..1, on fewer than two segments, on a buffer for an indeterminate bar, and on a ring with both a percent and content. | Slint properties cannot reject a value. | Values are clamped, fewer than two segments draw one, an indeterminate bar ignores its buffer, and the percent draws over any content. | A bad value shows the nearest valid bar instead of failing. |
| G44 | HostedWindow (AboutDialog, CrashReporter, UpdateDialog, SplashScreen windows), MiniWindow, WindowManager | Opens centered with a transparent title bar and the macOS lights at the theme's origin; Escape removes the window outright; the mark shows the name's first character. | Slint opens a window where the system places it and sets winit attributes only through an app-wide hook; Slint strings cannot be sliced. | `open_hosted`/`open_splash` center the window right after it shows and turn resizing and minimizing off; Escape runs `WindowChrome.close`, so a close check set with `guard_close` still applies; the mark takes the first grapheme through `TextFormat.grapheme-prefix` (needs `wire_text_format!`). | The window can show for a frame where the system put it; the system draws its usual title bar above the 38 px drag strip; a close check can keep a hosted window open on Escape. |
| G45 | MiniWindow, WindowManager, WindowSwitcher | A mini window is a pop-up window kind that floats over every app; the manager tracks gpui window handles and activates one with `activate_window`; the switcher reads the list on every frame. | Slint has no window kinds or window handles, and a `.slint` component cannot read Rust state. | The mini window is frameless and `always-on-top`; `WindowManager` (Rust) keeps a weak handle to each component and focuses it through winit; the switcher asks `ManagedWindows.list` when it shows and `wire_managed_windows!` fills it. | The mini window may not float over other apps' full-screen spaces as a macOS pop-up does; a window opened while the switcher is up appears at its next showing. |
| G46 | TrayIcon, Dock badge | A pick runs `on_pick(index, cx)` on gpui's app, through `AsyncApp::spawn`; its tests on macOS and Windows click the real icon. | Slint has no app context, and this port's CI runs on Linux. | `ely_slint::desktop` (feature `desktop`) keeps ely-desktop's platform code and hands each pick to `on_pick(index)` through `slint::invoke_from_event_loop`. The Linux tray is tested on a private session bus; the macOS and Windows code is type-checked for their targets. | The macOS status item and the Windows notification icon are not run by CI. |
| G47 | ButtonGroup | The group gives each button its slot (first, middle, last) and panics on fewer than two buttons. | A Slint component cannot set properties on children the owner declares. | The group is a row with no gap; each Button sets its own `group-slot`. | A button given the wrong slot draws the wrong corners, and a one-button group is not refused. |
| G48 | ToggleButton, ToggleGroup | Controlled: a press only reports the new state or selection, and the owner redraws with it. The selection is a list of values; a face with neither label nor icon panics. | Slint arrays cannot be searched or edited in `.slint`. | Both are `in-out` and take the new state at once, then report it (Slint's own idiom). A group asks the `Toggles` global, which `wire_toggles!` answers with `ely_slint::toggles`. A face without label or icon draws an empty square. | Unwired, no item shows on and a press clears the selection. An owner that refuses a change must set the state back. |
| G49 | FloatingActionButton | The entrance animates a top margin, so for 320 ms the button's box is up to 8 px taller and pushes what follows it in a layout. | Animating a size in a layout re-lays the parent each frame; Slint can, but it moves the neighbours. | The face is drawn lower inside a fixed 56 px box. | Neighbours in a column stay put while the button rises, where gpui's shift by up to 8 px. A floating action button is usually placed over content, where both look the same. |
| G50 | ShareButton | Panics when given neither text nor a link; its picker opens on macOS from gpui's own AppKit view. | Slint properties cannot reject a value; the picker needs the host's window, which `.slint` cannot reach. | With nothing to share it shows disabled. The `Sharing` global hands the press to the host; `wire_sharing!` (feature `desktop`) opens the picker on winit's AppKit view. | Unwired, the button shows disabled everywhere, macOS included. The macOS picker is type-checked by CI, not run. |
